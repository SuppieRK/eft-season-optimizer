# Security Policy

## Supported version

Security fixes apply to the current `main` branch and the current GitHub Pages deployment.

Older commits and local forks do not receive security fixes.

## Report a vulnerability

Do not include sensitive vulnerability details in a public issue.

Use [GitHub private vulnerability reporting](https://github.com/SuppieRK/eft-season-optimizer/security/advisories/new) to send a report.

Include this information:

- A clear description of the vulnerability
- The affected URL, file, or component
- Steps that reproduce the vulnerability
- The possible effect on users
- A proposed correction (optional)

If private reporting is unavailable, contact the maintainer through the GitHub profile. Ask for a private reporting channel.

Do not include exploit details in the contact request.

## Scope

The application is a static client-side site. It does not operate an application server or store user accounts.

Security reports can include these problems:

- Script injection or unsafe HTML rendering
- Disclosure of cookie data outside the local application
- Dependency or build-pipeline compromise
- Unsafe links or feedback data handling

Optimizer errors and incorrect game data are normal defects. Report these problems through a public GitHub issue.
